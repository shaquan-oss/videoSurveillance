# 企业智能知识中枢

私有文件底座 + 知识库 + 智能体门户。当前实现到**阶段一：账号与文件管理**。

| 阶段 | 内容 | 状态 |

## 快速启动

前置：Docker（含 compose）、Node ≥ 22、pnpm。

```bash
# 1. 装依赖
pnpm install

# 2. 起数据容器（Postgres / Redis / MinIO）
pnpm up:data

# 3. 建表 + 灌初始数据（首次）
pnpm db:migrate
pnpm db:seed

# 4. 起接口服务（3101）与前端（3100）—— 开两个终端分别跑
pnpm dev:api
pnpm dev:web
```

## 端口约定

> 本机 3000/3001 被另一个项目占用，本项目改用 3100（前端）/ 3101（接口）。

- 前端：http://127.0.0.1:3100
- 接口：http://127.0.0.1:3101/api（Swagger 文档在 `/api/docs`）
- 前端把 `/api` 反代到接口服务，浏览器同源访问，会话 Cookie 自动携带

## 目录结构

```
knowledge-hub/
├── apps/
│   ├── api/          # NestJS 接口服务（认证、文件、模型、健康检查）
│   ├── web/          # Nuxt 前端（登录、工作台、文件管理）
│   └── worker/       # 后台任务（文档解析/向量化，阶段二启用）
├── packages/
│   ├── shared/       # 前后端共用的类型、校验、常量、错误码
│   └── server-core/  # 数据库表结构、存储/向量/模型三个适配层、权限规则
├── docker-compose.dev.yml
└── .env              # 全部配置集中于此
```

## 三条抽象层（换供应商只改 .env）

- **存储**：S3 协议（MinIO ⇄ 移动云 EOS ⇄ 阿里 OSS），改 `S3_*` 三行
- **向量检索**：pgvector（切片超 500 万再换 Milvus/Qdrant）
- **模型**：聚智 OpenAPI（HMAC 签名，支持多模型 + 失败降级），改 `JIUTIAN_*` / `MODEL_REGISTRY`

## 关键设计（写代码前必读）

1. **权限在检索/查询阶段就过滤**，不是查出来再过滤——见 `server-core/permissions` 与 `pgvector.store`。
2. **数据库只存对象存储的 key，绝不存 URL/本地路径**——换存储时 URL 会失效，key 不会。
3. **下载走预签名链接**：后端校验权限后签发短时效地址，文件流不经过应用服务器。
4. **改密级必须同步更新已入库切片的权限标签**（否则出现「收紧了文件仍被检索到」的越权窗口）。
5. 前端只做按钮显隐，真正的拦截在后端守卫；前端藏按钮是体验优化，不是安全措施。

## 常用命令

```bash
pnpm typecheck          # 全仓类型检查
pnpm db:generate        # 表结构变更后生成迁移
pnpm db:migrate         # 应用迁移
pnpm db:seed            # 重灌初始数据（幂等）
pnpm db:reset           # 清空业务数据（开发环境，需 CONFIRM_RESET=yes）
```
